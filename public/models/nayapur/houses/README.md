# Nayapur house / frontage models

Currently using **Indian Bazaar Street and Temple** modules (CC0) as residential/shop frontages:

- `balcony-jali.glb`
- `corner-block.glb`
- `plaster-wall.glb`
- `compound-gate.glb`
- `external-stairs.glb`
- `rooftop-tank.glb`

These sit with the starter street in `../bazaar/starter-street.glb`.
